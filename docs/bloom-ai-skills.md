# Bloom AI — Skills & Abilities

Everything Bloom's coach can genuinely do in the shipped app, grouped by
area. Two layers are described together because they answer as one voice:

- **The online mind** (when a model is connected through the four optional
  API keys): conversation, reasoning, writing, vision. Skills marked ◇ live
  here — they are as broad as the model itself.
- **The Bloom layer**: reading your record, acting inside the app, photo
  nutrition, memory. Skills marked ◆ run on the app side and work even when
  no model is connected (in plainer form).

Nothing here is invented: every ◆ is implemented, every ◇ is a real
capability of the connected model used by this coach, and the coach never
claims data it doesn't have.
